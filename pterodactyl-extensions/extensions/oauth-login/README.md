# OAuth Login

Masuk ke Panel 2.0 dengan Discord, GitHub, atau Google. Rute publik `/extensions/oauth-login/{redirect,callback}/{provider}`, tombol di slot `auth.login.form.after`, banner galat di `auth.login.before`.

Pengaturan, keamanan, pemasangan, dan hasil uji: lihat [README proyek](../../README.md). Spesifikasi: [plan/01](../../plan/01-spec-oauth-login.md).
