# ADR-0001: English Language for Documentation

> **Status:** Accepted · **Date:** 2026-10-23

## Context

The documentation for itzg/docker-minecraft-server needs a consistent language. The upstream sources (GitHub README and ReadTheDocs) are in English. The user communicates in Indonesian but uses English technical terms.

## Decision

Write all documentation in English to match the authoritative sources and maintain consistency with the upstream project.

## Consequences

- Documentation is consistent with upstream sources
- English technical terms are preserved without translation
- Accessible to the broader Minecraft server community

## Alternatives Considered

- **Indonesian**: Would require translating all source content, introducing potential for errors and divergence from upstream
- **Bilingual**: Would double the documentation size and maintenance burden
